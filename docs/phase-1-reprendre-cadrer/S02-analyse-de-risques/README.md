## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Identifier les valeurs métier et les biens supports d'une organisation fictive ;
2. Décrire des sources de risque et des scénarios d'attaque plausibles ;
3. Estimer la gravité et la vraisemblance, placer les risques sur une matrice ;
4. Choisir des mesures, justifier leur priorité et décrire le risque résiduel ;
5. Rédiger une note de synthèse pour un dirigeant.
