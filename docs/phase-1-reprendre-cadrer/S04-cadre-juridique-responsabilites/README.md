Ici, partir de ces notions : qualification, sous-traitants, transferts, violations, responsabilité de l'administrateur.

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. Qualifier un traitement : responsable, sous-traitant, finalité, base légale ;
2. Expliquer les obligations liées aux sous-traitants et aux transferts de données hors de l'Union européenne ;
3. Situer le rôle du délégué à la protection des données et de la CNIL ;
4. Appliquer l'obligation de notification d'une violation de données (72 heures) ;
5. Situer les infractions d'atteinte aux systèmes (loi Godfrain) et la responsabilité de l'administrateur.
