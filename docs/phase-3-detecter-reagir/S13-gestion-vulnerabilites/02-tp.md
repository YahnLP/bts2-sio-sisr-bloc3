## Partie C – Calculer un score CVSS (≈ 35 min)

### C1 – À la main

Pour chaque vecteur, **devine** la qualification (faible, moyenne, élevée, critique) **avant** tout calcul :

| Vecteur | Description | Ma qualification |
|---|---|---|
| `AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N` | Un inconnu lit un fichier confidentiel par Internet | |
| `AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H` | Un utilisateur du poste devient administrateur | |
| `AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N` | Un script s'exécute dans le navigateur d'un autre utilisateur | |

### C2 – Avec l'outil

Sur `scan`, crée `cvss.py` :

```python
#!/usr/bin/env python3
# Calcul du score de base CVSS v3.1 : python3 cvss.py "AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H"
import sys, math

def arrondi(x):                       # arrondi au dixieme superieur
    n = round(x * 100000)
    return n / 100000.0 if n % 10000 == 0 else (math.floor(n / 10000) + 1) / 10.0

def score(vecteur):
    m = dict(p.split(":") for p in vecteur.replace("CVSS:3.1/", "").split("/"))
    av = {"N": 0.85, "A": 0.62, "L": 0.55, "P": 0.2}[m["AV"]]
    ac = {"L": 0.77, "H": 0.44}[m["AC"]]
    ch = m["S"] == "C"
    pr = {"N": 0.85, "L": 0.68 if ch else 0.62, "H": 0.5 if ch else 0.27}[m["PR"]]
    ui = {"N": 0.85, "R": 0.62}[m["UI"]]
    imp = {"H": 0.56, "L": 0.22, "N": 0.0}
    iss = 1 - (1 - imp[m["C"]]) * (1 - imp[m["I"]]) * (1 - imp[m["A"]])
    impact = 7.52 * (iss - 0.029) - 3.25 * (iss - 0.02) ** 15 if ch else 6.42 * iss
    expl = 8.22 * av * ac * pr * ui
    if impact <= 0:
        return 0.0
    return arrondi(min(1.08 * (impact + expl), 10)) if ch else arrondi(min(impact + expl, 10))

if __name__ == "__main__":
    print(score(sys.argv[1]))
```

```bash
python3 cvss.py "AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N"
python3 cvss.py "AV:L/AC:L/PR:L/UI:N/S:U/C:H/I:H/A:H"
python3 cvss.py "AV:N/AC:L/PR:N/UI:R/S:C/C:L/I:L/A:N"
```

| Vecteur | Score | Qualification | Ma devinette était-elle juste ? |

| 3 | | | |
