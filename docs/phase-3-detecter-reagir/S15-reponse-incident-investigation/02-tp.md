## Le scénario (fictif)

**Lundi 9 mars, 7 h 45.** Le bureau d'études de l'Atelier Verdier ne peut plus ouvrir ses plans : les fichiers du serveur portent l'extension `.verrou` et un fichier `LISEZ-MOI.txt` demande une rançon. Le responsable administratif (deux heures d'informatique par semaine) vous appelle. **Aucune donnée ne vous est encore connue** : vous disposez de trois **journaux fournis**, extraits du collecteur et de la box. Toutes les adresses et tous les noms sont **fictifs** ; les adresses `203.0.113.x` et `198.51.100.x` sont réservées à la documentation.

| Fichier | Contenu |
|---|---|
| [`authentification.log`](journaux-fictifs/authentification.log) | Connexions, comptes créés, services arrêtés |
| [`pare-feu.log`](journaux-fictifs/pare-feu.log) | Flux notables de la box |
| [`fichiers.log`](journaux-fictifs/fichiers.log) | Opérations sur le serveur de fichiers |

Le réseau de l'atelier est celui du dossier de la séance S02 : un seul réseau, l'accès distant (port 3389) redirigé sur la box vers le PC de la comptable (`192.168.1.20`), le serveur de fichiers `192.168.1.10`, le NAS de sauvegarde `192.168.1.50`.

**Contraintes.** Une machine Linux (celle de tes séances). Télécharge les trois fichiers dans un dossier `~/incident/originaux`.

## Partie B – Préserver les preuves (≈ 30 min)

### B1 – Copier et prendre l'empreinte

```bash
cd ~/incident
mkdir -p copies
sha256sum originaux/*.log > empreintes.sha256
cat empreintes.sha256
cp originaux/*.log copies/
(cd copies && sha256sum -c ../empreintes.sha256 2>&1 | head -3) || true
```

Les deux dernières lignes sont piégeuses : relis le chemin dans `empreintes.sha256` et explique pourquoi la **vérification** doit se faire dans le **bon dossier**. Corrige la commande pour vérifier **les copies**.

### B2 – Constater qu'une altération se voit

```bash
echo "ligne ajoutee" >> copies/pare-feu.log
sha256sum copies/*.log | sed 's#copies/#originaux/#' | diff - empreintes.sha256
```

**J'anticipe.** Quel fichier la commande signale-t-elle ? Que se passe-t-il si **un seul octet** change ? ______________________

Retire ensuite la ligne ajoutée en recopiant depuis les originaux (`cp originaux/pare-feu.log copies/`) et vérifie que tout est conforme.

## Partie C – Reconstituer la chronologie (≈ 60 min)

Travaille **sur les copies**.

### C1 – Premiers constats

```bash
cd ~/incident/copies
# Echecs de connexion par adresse source
grep echec_connexion authentification.log | grep -o 'source=[^ ]*' | sort | uniq -c | sort -rn
# Premiere et derniere ligne de cette adresse suspecte
grep 'source=203.0.113.77' authentification.log | head -1
grep 'source=203.0.113.77' authentification.log | tail -2
# Le succes
grep 'succes_connexion' authentification.log | grep 203.0.113.77
```

**J'anticipe.** Que vas-tu trouver comme adresse **dominante** parmi les échecs ? Les deux échecs isolés sont-ils inquiétants ? ______________________

### C2 – Les actions de l'attaquant

```bash
grep -E 'creation_compte|arret_service|suppression_sauvegardes' authentification.log
grep -E 'sortant-inhabituel|volume_envoye' pare-feu.log
```

### C3 – La chronologie fusionnée

```bash
cat authentification.log pare-feu.log fichiers.log | sort | grep -E '203\.0\.113\.77|svc-maint|suppression_sauvegardes|sortant-inhabituel|sauvegarde-nocturne|LISEZ' | grep -v 'echec_connexion compte=[a-z-]* source=203'
```

### C4 – Le chiffrement

```bash
grep -c renommage fichiers.log
grep renommage fichiers.log | head -1 | cut -c1-19
grep renommage fichiers.log | tail -1 | cut -c1-19
grep renommage fichiers.log | grep -o 'dossier=[^ ]*' | sort | uniq -c | sort -rn
```

**Je comprends.**

1. Quel est le **point d'entrée** de l'attaque ? Quelle faiblesse du dossier de la séance S02 l'explique ? ______________________
2. Combien de **temps** s'écoule entre l'entrée et le début du chiffrement ? Pourquoi l'attaquant a-t-il attendu ? ______________________
3. Quelles actions visaient à **empêcher la reprise** ? ______________________
4. Le journal du **pare-feu** montre un flux sortant inhabituel **avant** le chiffrement : que faut-il en conclure, et pourquoi cela change-t-il les **obligations** de l'entreprise ? ______________________
5. Un journal manque : lequel, et que cela empêche-t-il de prouver ? (Aide : de quelle machine viennent les journaux de l'authentification du PC de la comptable, et que faire pour en avoir un autre ?) ______________________

**Point de contrôle :** chronologie remplie, avec les lignes citées.
