> [!NOTE]
> **Question qui guide la séance :** *« Comment démontrer qu'une faiblesse est réellement exploitable, sans mettre l'organisation en danger ? »*

## Objectifs

À la fin de la séance, l'étudiant est capable de :

1. **Rappeler** le cadre légal d'un test : autorisation écrite, périmètre, règles d'engagement ;
2. Dérouler la démarche d'un test (reconnaissance, évaluation, exploitation en laboratoire, rapport) ;
3. Rédiger un rapport d'audit avec preuves, gravité et recommandations ;
4. Présenter les résultats à un responsable non technique.

## Contenu prévu

- Cours : types d'audits, démarche, cadre légal, rapport
- TP : audit d'un laboratoire isolé et rapport
- Aide-mémoire : plan de rapport, règles d'engagement
